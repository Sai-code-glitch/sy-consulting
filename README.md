# SY Consulting

Website for SY Consulting, a study-abroad consultancy that guides students from university shortlist to landing in the USA, UK, Canada, Australia, Germany and Ireland.

Live site: https://sai-code-glitch.github.io/sy-consulting/

- Edit contact details, prices, booking hours and the payment link in `js/config.js`.
- `LAUNCH.md` has the setup guide (enquiry email activation, payments, custom domain).
